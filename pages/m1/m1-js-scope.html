② 深入浅出

一、值分两种：基本类型与引用类型

基本类型（number、string、boolean、undefined、null、symbol、bigint）的值直接存在「栈」里： 复制变量时复制的是值本身，两份从此互不相干。 引用类型（对象、数组、函数）的实体放在「堆」里，变量里只存一张指向它的「地址小票」： 复制变量复制的是小票，于是两个变量操纵的是同一个对象——这就是为什么 b.push(3) 之后 a.length 也变了。

二、判断类型的三板斧

typeof 能区分大部分基本类型（但 typeof null === 'object' 是历史遗留 bug，函数倒是会返回 'function'）； instanceof 沿原型链回答「这个值是不是某个构造函数造出来的」； Object.prototype.toString.call(x) 最精准，能返回 '[object Array]' 这样的准确标签。

三、作用域与作用域链

作用域就是变量的「有效房间」：函数每被调用一次，就新开一间房。 在房间里用到一个变量时，JS 从当前房间开始找，找不到就推门出去到外层房间找，一路找到全局—— 这条「逐级向外」的查找路线叫作用域链。关键是：路线在函数定义时就定好了（词法作用域），与函数在哪儿被调用无关。

四、变量提升与暂时性死区

var 的声明会被「提升」到函数顶部，所以在声明之前访问它得到 undefined（不报错）——这是历史包袱。 let/const 其实也会提升，但在声明语句执行前处于暂时性死区：访问直接抛 ReferenceError。 const 的「绑定」不可重新赋值，但对象的内容（属性）依然可以修改。

五、闭包：函数记住了出生地

内层函数引用了外层函数的变量，当外层函数已经返回、按理说变量该销毁时，这些变量却因为被内层函数「惦记着」而继续存活，且只属于这一个内层函数——这就是闭包。

function makeCounter() {
  var count = 0;              // 被内层函数记住的私有变量
  return function () {
    count = count + 1;
    return count;
  };
}
var c1 = makeCounter();
var c2 = makeCounter();
c1(); c1();  // c1 各自计数，返回 2
c2();        // c2 是另一个独立闭包，返回 1
生活类比 · 作用域链像小区门禁

小李住 3 栋 502：在自己家里（当前作用域）拿什么私人东西都行；想借工具就出房门去客厅（外层函数作用域）， 还没有就下楼去小区便利店（全局作用域）——查找永远「从里向外」逐级走，且路线在你搬进来那天（函数定义时）就固定了。 如果便利店也没有，就是「查无此人」，直接报 ReferenceError。反过来，便利店的东西（全局变量）全小区都够得着，但住在楼里的私人东西，外人是摸不到的。

生活类比 · 闭包像外卖柜

下班前，你把外卖放进公司楼下的外卖柜（外层函数把变量留在内存里），然后回家了（外层函数执行完毕、调用栈清空）。 但你手里还捏着取件小票（内层函数的引用）——晚上到家想吃了，凭小票照样开柜取出当初存的东西。 而且柜子按小票隔离：你的小票开不了别人的柜子（闭包变量对外不可见，等效私有变量）。 函数回到「家」里，仍能凭小票取出「出生地」存放的东西，这就是闭包。

⑦ 面试视角

问法一：下面代码输出什么？如何让它输出 0、1、2？ 
for (var i = 0; i < 3; i++) {
  setTimeout(function () { console.log(i); });
}
  • 输出 3、3、3：var 是函数作用域，三次回调共享同一个变量 i；回调进入任务队列，等同步代码（整个循环）跑完才执行，此时 i 已停在 3。
  • 方案一：把 var 改成 let——每轮迭代创建一个独立的块级绑定，回调各自记住当轮的 i。
  • 方案二：包一层 IIFE，把 i 当参数拷贝进函数作用域（旧代码兼容写法）。
  • 加分项：点出「回调执行时机由事件循环决定」，能自然过渡到事件循环考点。
问法二：什么是闭包？它一定会导致内存泄漏吗？
  • 定义：函数与它定义时所在词法作用域的组合——内层函数持有外层变量的引用，外层返回后变量依然存活。
  • 常见应用：计数器与私有变量、函数柯里化、防抖节流里保存定时器 id、模块模式。
  • 泄漏场景：闭包意外长期持有大对象或 DOM 引用——典型是忘了清理的定时器回调、事件监听闭包。
  • 准确的结论：闭包本身不是泄漏元凶，「不该活着的引用一直活着」才是；解决办法是及时 clearInterval、移除监听、把不再需要的引用置 null。
  • 加分项：现代引擎按「可达性」回收，只被闭包引用的变量不会被误回收；能说出这一点说明懂 GC 思路。
