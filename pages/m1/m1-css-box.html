② 深入浅出

四层结构：content、padding、border、margin

每个元素都是四层同心结构，由内到外：content 是内容本身（文字、图片）； padding 是内容与边框之间的内边距，属于元素自己，背景色默认会画到这一层； border 是边框线，有粗细与样式； margin 是元素与邻居之间的外边距，完全透明、不属于元素自身。一个元素「实际占据的水平空间」，就是这四层的横向总和。

box-sizing：width 到底管到哪一层

关键分歧在于：width 写的数字指的到底是哪一层？

  • 标准盒模型（content-box，默认）：width 只指 content。padding 和 border 会「额外撑大」元素——写 width:200px 再加 20px padding，实际占位 240px+；
  • IE 盒模型（border-box）：width 指到 border 为止（content + padding + border）。写 width:200px，无论 padding/border 怎么调，边框外沿永远 200px，content 自动被压缩。

日常选型的约定俗成：全局设 * { box-sizing: border-box; }。因为「我写了多宽它就多宽」符合直觉，增删 padding 不会把布局挤乱——几乎所有现代 CSS 框架都这么干。

Flex：排队上公交——一根轴上的伸缩分配

给父容器设 display: flex，子元素就沿「主轴」排成一队，垂直于主轴的是「交叉轴」。flex-direction 决定主轴方向（row 横 / column 纵）。 空间分配看三兄弟：flex-basis 是上车前「想占的座位宽」，flex-grow 是「有剩余空间时按什么比例分」，flex-shrink 是「空间不够时按什么比例让」。 分配公式：剩余空间 = 容器宽 − Σbasis，每人分得 剩余空间 × 自己的 grow ÷ Σgrow。常用 flex: 1 即 grow:1 shrink:1 basis:0%——人人平分剩余空间。

Grid：电影院对号入座——先画座位表再入座

给父容器设 display: grid，用 grid-template-columns / grid-template-rows 先画出列与行的「座位表」，子元素按顺序自动入座。 单位 fr 表示「剩余空间的份数」：1fr 2fr 就是把空间按 1:2 切。经典栅格 repeat(12, 1fr) 一步画出 12 列栅格，配合 gap 控制间距。二维布局（行 + 列同时规划）选 Grid，一维排队能伸能缩选 Flex。

面试常客：垂直水平居中

至少备好三种写法：① 父 display:flex + justify-content:center + align-items:center；② 父 display:grid + place-items:center（最短）；③ 子绝对定位 + top/left:50% + transform:translate(-50%,-50%)（不依赖父尺寸，兼容老浏览器）。

生活类比 · 快递包裹、公交与电影院

盒模型像一只快递包裹：商品是 content，四周垫的泡沫棉是 padding（减震，属于包裹内部），纸箱板是 border（围出边界），包裹与包裹之间要求的摆放间距是 margin（不属于包裹，只是邻居间的距离）。快递单上写「箱内物品 200cm」指的是商品本身（content-box）；如果写「整箱外沿 200cm」，那泡沫棉再厚也得从 200 里抠（border-box）。

Flex 像排队上公交：一队人沿车门方向站好（主轴），车上空位多就按约定比例舒展开站（flex-grow），人太多就按比例挤一挤（flex-shrink）。Grid 像电影院对号入座：开场前座位表（行列模板）已经画好，观众按票根顺序坐下，谁也不用挤——二维空间各就各位。

④ 知识联结

前置依赖：HTML 语义化与页面结构 —— 盒模型排版的对象，正是语义化标签搭出的结构。

向后延伸：盒模型是浏览器「布局（Layout）」一步的计算依据，学渲染流水线与重排重绘时，你会知道改一次 padding 的真实代价；布局尺寸突变还是性能指标 CLS（累积布局偏移）的头号元凶。

交叉链接：

  • 浏览器渲染流水线 —— DOM + 盒模型 → 布局 → 绘制，盒子是在哪一步被算出尺寸的
  • 重排、重绘与合成层 —— 为什么改 margin 会触发重排、改 transform 却不会
  • Core Web Vitals 性能指标 —— CLS 专抓「页面乱跳」，根因常是没约束好的盒尺寸

⑦ 面试视角

问法一：谈谈 CSS 盒模型，标准盒模型与 IE 盒模型的区别？项目里怎么选？
  • 四层结构：content → padding → border → margin；占据总宽 = width(所指层) + padding + border + margin 中未计入 width 的部分。
  • content-box：width 只指内容区，padding/border 向外撑大；border-box：width 管到 border 外沿，内容区 = width − padding − border。
  • 选型：全局 * { box-sizing: border-box }，写多宽就多宽，增减 padding 不破坏布局；margin 永远不计入 width。
问法二：垂直水平居中有哪几种写法？
  • Flex：父级 display:flex + justify-content:center + align-items:center，最通用。
  • Grid：父级 display:grid + place-items:center，声明最短。
  • 绝对定位 + transform：子元素 top/left:50% + translate(-50%,-50%)，无需知道父子尺寸。
  • 加分项：绝对定位 + margin:auto（四方向为 0）；定高定时也可用 line-height / text-align 这类文本方案。
