② 深入浅出

先看一个「面条页」

很多初学者写页面时只认识两个标签：<div> 和 <span>，于是整个页面长这样： 头部是 <div class="top">，导航是 <div class="menu">，正文还是 <div>…… 页面渲染出来毫无问题——但代码里只有我们自己（凭 class 名）知道哪块是什么。 浏览器、搜索引擎和读屏器看到的是一排排「无名盒子」，它们只能靠猜。

语义化标签全景：一张报纸的五个分区

把网页想象成一张报纸，语义化标签就是「印在版面上的栏目名」：

  • <header>：报头。页面或某个区块的头部，放 Logo、站名、导语；
  • <nav>：目录栏。主导航链接的集合，读屏器可以一键跳过或直达；
  • <main>：正文版面。页面最核心的内容，整个页面通常只出现一次；
  • <article>：一篇独立成篇的稿子（新闻、评论、博客文章），抽出去单独看也完整；
  • <section>：稿子里的一个章节，通常带自己的标题；
  • <aside>：边栏。与主体关联较弱的内容：相关推荐、标签、广告；
  • <footer>：报尾。版权信息、备案号、联系方式。

注意：<div> 和 <span> 并没有被废弃——当一块内容找不到合适的语义标签、纯粹为了排版分组时，用它们完全正确。语义化的意思是「有含义时用有含义的标签」，而不是「永远不许用 div」。

语义化的三大收益

  1. SEO 友好：搜索引擎靠标签理解页面。爬虫读到 <nav> 就知道这是导航、读到 <article> 里的 <h1> 就认为这是文章主题——结构越清晰，收录和排名越占便宜；
  2. 无障碍可访问：读屏器用户可以按「地标（landmark）」和「标题层级」快速跳转。全是 div 的页面没有地标，只能从头逐行听完；
  3. 代码可维护：半年后回看 <header> 不需要注释就能懂，而 <div class="top-2-new"> 连作者自己都要回忆半天。

标题层级 h1~h6：大纲不能跳级

h1 到 h6 表达的是文档大纲的层级，不是「字号从大到小」。正确用法：h1 是文章主标题（一页通常一个）；h2 是它下面的小节；h3 是 h2 的再细分——逐级递进，不跳级。 「从 h1 直接跳到 h4」会让读屏器用户误以为缺了一整层内容；「页面里塞十几个 h1」则会稀释每个标题的权重。想要大字号，请用 CSS 改样式，而不是选一个字号大的标签。

strong/b 与 em/i：重要性和单纯样式是两回事

<strong> 表示「内容上很重要」，<em> 表示「语气上的强调」，读屏器会用更重的语气朗读它们； 而 <b> 和 <i> 只改变视觉样式（加粗、斜体），不表达任何强调含义，适合关键词高亮、外来词、书名号这类场景。拿不准就用语义版本。

生活类比 · 超市货架

想象你第一次进一家新超市：门口挂着「生鲜 / 日用品 / 零食」的分区指示牌，你不用问店员，顺着牌子三步就找到牛奶。语义化标签就是这些指示牌——<header> 是入口导购牌，<nav> 是悬挂的分区指示，<main> 是主货架区，<aside> 是收银台旁的促销架。

搜索引擎像一个只能「看牌子」的新顾客：牌子清楚，它就能把「牛奶在生鲜区」记进小本本（收录与排名）；读屏器像一位闭着眼睛的顾客，全靠广播播报「生鲜区到了」来逛店——全是 div 的超市等于所有货堆在一个大箱子里，还都贴着「箱子1」「箱子2」的标签，两种顾客都寸步难行。

⑥ 巩固复习

一句话讲给外行听：语义化就是用「写着名字的标签」给页面分区——报头、导航、正文、边栏、页脚各归各位，让人、搜索引擎和读屏器都一眼看懂页面结构，而不是一堆无名的黑盒子。

建议复习时间：今天睡前合上页面，凭记忆画出「一张报纸五个分区」对应的 5 个标签；1 天、3 天、7 天后各回来重做一遍例题（对应遗忘曲线 1/3/7 天间隔），站点会在地图页标出「该复习了」。

⑦ 面试视角

问法一：为什么要强调语义化？语义化带来了什么好处？
  • 对机器：标签自带含义，搜索引擎据此理解页面结构与内容权重（SEO）；读屏器靠标签生成地标与标题大纲，支持快捷跳转（无障碍）。
  • 对人：代码即文档，header/nav/main 自解释，降低团队维护成本。
  • 加分项：能说出 main 全页唯一、section 应带标题、div 用于「无语义的纯排版分组」等边界用法。
问法二：strong 与 b、em 与 i 有什么区别？h1~h6 该怎么用？
  • strong/em 是语义标签：分别表示「内容重要」与「语气强调」，读屏器会重读；b/i 只改视觉样式，不含强调语义，适合关键词、外来词等纯排版场景。
  • h1~h6 表达文档大纲层级：逐级递进不跳级；h1 通常全页一个（article 内可各自拥有）；字号大小交给 CSS，不靠选标签。
  • 加分项：提到跳级会让读屏器大纲断裂、滥用 h1 会稀释标题权重。
