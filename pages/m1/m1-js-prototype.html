② 深入浅出

一、prototype、__proto__、constructor 的三角关系

每个函数天生自带一个 prototype 属性——它是一个对象，将来作为「这批实例的公共储物柜」。 每个实例身上有一个隐藏通道 __proto__，指向造它的构造函数的 prototype： 一句话记住三角关系——实例.__proto__ === 构造函数.prototype； 而 prototype 上的 constructor 又指回构造函数本身，方便回答「我是谁造的」。

二、原型链查找与属性遮蔽

读一个属性时，先看对象自己有没有；没有就顺着 __proto__ 找它的原型，再没有继续向上，一路到 Object.prototype，尽头是 null。 整条路找完都没有，返回 undefined（注意：读属性不报错，与「读一个未声明变量抛 ReferenceError」不同）。 若对象自己有同名属性，就遮蔽（shadowing）原型上的版本——先吃自己窝里的。

三、this 的四种绑定规则

默认绑定：独立调用 fn()，非严格模式 this 指向 window（严格模式是 undefined）。 隐式绑定：obj.fn() 谁点的名就指谁，this 是 obj。 显式绑定：call/apply 立即调用并强行指定 this（参数列表 vs 数组的差别），bind 则返回一个绑死 this 的新函数。 new 绑定：this 指向刚创建的新对象。优先级口诀：new > 显式 > 隐式 > 默认。

四、箭头函数没有自己的 this

箭头函数的 this 在定义处就继承自外层作用域，与怎么调用无关，call/apply 也改不动。 所以「对象方法里要用外层 this」时它是利器；而「需要看调用者」的方法（如事件回调里的 this）就别用它。

五、手写 new 的四步拆解

① 收集除构造函数外的实参；② 用 Object.create(Constructor.prototype) 创建原型指向正确的新对象； ③ 以新对象为 this 执行构造函数，拿到返回值 ret；④ ret 是对象或函数就返回 ret，否则返回新对象。 例题区会亲手实现一遍。

生活类比 · 原型链像家谱

小柴犬旺财想吃火腿肠：先翻自己窝（实例自身属性），没有；去问妈妈——「狗」这一辈的公共柜子（Dog.prototype），找到了就拿来用； 妈妈那辈也没有，就再问外婆——「动物」的公共柜子；一路问到开天辟地的祖宗（Object.prototype）还没有，就耸耸肩说「没有」（undefined），但不会吵起来（不报错）。 长辈柜子里的东西旺财都能用；可旺财自己窝里若也藏了一根，它一定先吃自己的——这就是属性遮蔽。

生活类比 · this 像「我」这个字

「我要吃饭」这句话，你说出口，「我」就是你；你爸说，「我」就是你爸——同一句话（同一个函数），谁在说（谁调用）决定「我」指谁，这是隐式绑定。 开会时主持人指着小王说「现在这个『我』代表经理发言」（call/apply 强行指定），这是显式绑定。 而「我」若是写在出生证明上的（箭头函数），从出生那刻就固定了，事后谁也改不了。

⑦ 面试视角

问法一：new 操作符到底做了什么？class 和原型是什么关系？
  • 四步：创建一个新对象；把新对象的 __proto__ 指向构造函数的 prototype；以新对象为 this 执行构造函数；构造函数返回对象/函数时用它，否则返回新对象。
  • 因为第 2 步建立了原型连接，所以 o instanceof Constructor 成立（instanceof 就是沿原型链找 Constructor.prototype）。
  • class 是原型的语法糖：class 里写的方法实际挂在 prototype 上；extends 底层同样是原型链 + this 的传递。
  • 加分项：手写 new 时用 Object.create(Constructor.prototype) 一步完成「建对象 + 连原型」。
问法二：写出下面三行分别输出什么？为什么？ 
var name = 'window';
var obj = {
  name: 'obj',
  say: function () { console.log(this.name); }
};
obj.say();      // 第一行
var f = obj.say;
f();            // 第二行
f.call(obj);    // 第三行
  • 第一行输出 'obj'：obj.say() 是隐式绑定，谁点的名（点号前是谁）this 就指谁。
  • 第二行输出 'window'：把方法赋给 f 后变成独立调用，隐式绑定丢失，走默认绑定指向全局（非严格模式）。
  • 第三行输出 'obj'：call 显式绑定了 this，强行指回 obj。
  • 结论口诀：this 看调用点不看定义点；优先级 new > 显式 > 隐式 > 默认；箭头函数例外（词法 this，改不动）。
