② 深入浅出

1. 变量声明升级：let 与 const

let/const 相比 var 有三大升级：① 块级作用域——一对 {} 就是一个独立房间，出房门就看不见；② 不可重复声明——同名标签一房间只挂一个；③ 暂时性死区（TDZ）——声明语句执行之前访问直接抛 ReferenceError，而不是像 var 那样安静地给你一个 undefined。经典差异体现在循环里：

for (var i = 0; i < 3; i++) {
  setTimeout(function () { console.log(i); }); // 打印 3 3 3：三个回调共用同一个 var i
}
for (let j = 0; j < 3; j++) {
  setTimeout(function () { console.log(j); }); // 打印 0 1 2：每轮循环都是一个全新的 j
}

const 声明的是「不可重新赋值的绑定」：不能 a = 别的，但对象/数组内部内容仍可修改——锁的是「钥匙不能换锁」，不是「房间里的东西不能动」。实践口径：默认 const，需要重新赋值才用 let，不再写 var。

2. 解构赋值：一次拆包

解构是「按 pattern 取物」：对象解构按属性名取（顺序无关），数组解构按位置取，两者都支持默认值与重命名：

const trip = { city: '成都', days: 3, gear: ['伞', '充电宝'] };
const { city, days } = trip;              // 按名取：city='成都', days=3
const { city: c, note = '无备注' } = trip; // 重命名 + 默认值：c='成都', note='无备注'
const [first, second] = trip.gear;        // 按位取：first='伞', second='充电宝'
function greet({ name, city }) { ... }    // 函数参数也能解构，调用即拆包

3. 展开 / 剩余运算符：... 的两副面孔

同一个 ...，「摊开」时是展开运算符，「收拢」时是剩余（rest）：

const arr = [1, 2, 3];
const copy = [...arr, 4];              // 展开：合并数组 → [1,2,3,4]
const obj2 = { ...trip, days: 5 };     // 展开对象并覆盖属性（浅拷贝）
function sum(...nums) { return nums.reduce((a, b) => a + b, 0); } // 收拢成数组
const { city, ...rest } = trip;        // 点名的拿走，剩下的打包进 rest

4. 模板字符串

反引号字符串支持 ${表达式} 内嵌与多行书写，从此告别 'a' + x + 'b' 的加号马拉松，也告别手拼换行符。

5. 箭头函数：更短，而且「没有自己的 this」

箭头函数除了写法紧凑，更本质的区别是：它不创建自己的 this、arguments，而是沿用「定义时所在外层作用域」的 this——普通函数的 this 由「谁调用」决定，箭头函数的 this 由「在哪定义」决定。代价是它不能当构造函数（new 会报错）、也不适合做需要动态 this 的对象方法或 DOM 事件回调。

6. 进阶速览：Map / Set、可选链、空值合并、Proxy

  • Map / Set：Map 可以用任意类型做键（对象当键时比普通对象可靠）；Set 天然去重：[...new Set(arr)]。
  • 可选链 ?.：遇到 null/undefined 不再报错，而是短路返回 undefined，深层数据放心访问：res?.data?.list。
  • 空值合并 ??：只在左侧是 null/undefined 时取右侧；与 || 的区别是 0、''、false 不会被误判为「空」。
  • Proxy：对整个对象的读写做全面拦截，Vue 3 的响应式正是基于它。

⑦ 面试视角

问法一：箭头函数与普通函数的区别有哪些？
  • this：普通函数由调用方式决定（默认/隐式/显式/new 四种绑定）；箭头函数没有自己的 this，沿用定义时外层作用域，call/apply/bind 也改不动。
  • arguments：箭头函数没有自己的 arguments（可用剩余参数 ...args 代替）。
  • 构造能力：箭头函数没有原型与内部构造方法，用 new 调用直接报错。
  • 适用边界：适合回调、需要沿用外层 this 的场景；不适合对象方法、原型方法、需要动态 this 的事件回调与构造函数。
问法二：var、let、const 三者声明变量有什么区别？
  • 作用域：var 是函数作用域；let/const 是块级作用域（一对花括号一个房间）。
  • 提升行为：var 声明提升并初始化为 undefined；let/const 也提升但不初始化，声明前访问抛 ReferenceError（暂时性死区）。
  • 重复声明：var 允许重复声明；let/const 同一作用域内不允许。
  • 重赋值：const 的绑定不可重新赋值，但对象/数组内部内容仍可修改。
  • 实践结论：默认 const，需要重新赋值用 let，新代码不再使用 var。
